# JTQB Sales Prototype

응급처치학개론 문제 판매 웹사이트의 공개 검토용 시제품입니다.

- 실제 결제, 문자 인증, 이메일·카카오톡 발송, 문제 파일 다운로드는 연결되어 있지 않습니다.
- 실제 개인정보나 결제정보를 입력하지 마세요.
- 고객·관리자 데이터는 각 방문자의 브라우저 `localStorage`에만 저장됩니다.

## 체험 계정

- 일반 회원: `user@jtqb.test` / `jtqb1234`
- 관리자: `admin` / `admin1234`
- 회원가입 테스트 인증번호: `123456`
